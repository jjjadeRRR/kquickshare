# KQuickShare 0.4.0

Send and receive Android Quick Share files and text from KDE Plasma 6, without a
companion Android application. This release improves installation beyond Arch
and adds configurable reception into the clipboard.

- Independent settings for received photos, received text and saving text as files.
  Handles Android shared text and UTF-8 `.txt` attachments; existing files are preserved.
- Background clipboard access on Plasma Wayland through KDE's system clipboard API.
- Source installer detects Arch, Debian/Ubuntu, Fedora and openSUSE package families.
- Debian 13 and Fedora 43 builds tested in clean containers, including encrypted
  transfer peers and GUI/core tests; Ubuntu 26.04 is a CI target.
- Debian and Fedora native packages, versioned Arch PKGBUILD, AppStream metadata,
  generic screenshots and a structured bug-report form.
- Receive TCP port configurable in Settings, default 53318. Optional firewalld
  service definition; no firewall changes are made automatically.
- Main application tests no longer require private Plasma clipboard QML. The
  optional history-button installer refuses Plasma series other than 6.8.x.
- Desktop and Dolphin launchers use the installed executable path.

## Choose the right download

- `kquickshare-0.4.0.tar.gz`: source archive; extract and run `./install.sh` as your
  desktop user. Dependencies may require sudo. Requires Qt 6.8+, KF6 and OpenSSL 3.
- `kquickshare_0.4.0_amd64.deb`: **Debian 13 x86_64**, install with
  `sudo apt install ./kquickshare_0.4.0_amd64.deb`.
- `kquickshare-0.4.0-1.x86_64.rpm`: **Fedora 43 x86_64**, install with
  `sudo dnf install ./kquickshare-0.4.0-1.x86_64.rpm`.
- `PKGBUILD`: **Arch Linux**, review and run `makepkg -si` in its directory.
- `SHA256SUMS`: checksums for the attached files.

Do not install the Debian package on an arbitrary Ubuntu release, or the Fedora
RPM on openSUSE. Use the source installer if no matching package is available.

Real-phone testing remains primarily Arch / Plasma 6.8 / Pixel 7 Pro. Container
checks establish build and protocol compatibility, not a guarantee for every
phone or desktop version. See the compatibility document and GitHub Actions.
Plasma 5 is not supported. This remains an AI-assisted/vibe-coded community project.

Both devices must be on the same LAN. Discovery needs UDP 5353, and incoming
transfers use TCP 53318 by default. Enable firewall access only on a trusted LAN.
Trust matching is based on device name, type and IP, not a permanent verified key.
BLE activation, Wi-Fi Direct and Google-account contact discovery are not implemented.
