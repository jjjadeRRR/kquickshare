# KQuickShare 0.6.0

## Bluetooth reception

- Android can discover the PC over Bluetooth Low Energy. KQuickShare offers
  a switch to the local network for file data. If a LAN connection cannot be
  established, the phone can continue over Bluetooth.
- Bluetooth reception requires a powered BlueZ adapter with extended BLE
  advertising. Sending from the PC uses LAN discovery.
- The desktop app asks for approval on every transfer that starts over
  Bluetooth, including transfers that switch to LAN. Direct LAN transfers can
  still use the trusted-device list.
- The debugging receiver `kquickshare-cli` listens on LAN by default. Its
  `--bluetooth` flag enables automatic reception from nearby Bluetooth devices.

Thanks to [Nikita Veselov (@veselv2010)](https://github.com/veselv2010) for
implementing Bluetooth reception and testing it on Android.

## LAN fixes

- LAN discovery retries after a temporary mDNS failure.
- Direct LAN transfers ignore bandwidth-negotiation frames when a handoff is
  inactive and use the same disconnect message as earlier releases.
- Cancelling a transfer during a Bluetooth-to-LAN switch releases the
  connection slot.

LAN discovery uses UDP 5353. Direct reception uses TCP 53318 by default.
Switching from Bluetooth to LAN uses an additional temporary TCP port.

## Downloads

- `kquickshare-0.6.0.tar.gz` is the source archive. Extract it and run
  `./install.sh` as your desktop user.
- `PKGBUILD` is for Arch Linux. Review it, then run `makepkg -si`.
- Use the binary package matching your distribution. Debian 13 uses `.deb`,
  Fedora 43 uses `-1.x86_64.rpm`, and ALT Linux p11 uses `-alt1.x86_64.rpm`.
- `SHA256SUMS` lists the checksums for the release downloads.
