# KQuickShare 0.5.0

Code quality, reliability, accent-coloured icons and new receiving options.
Existing settings and trusted devices keep working.

## New

- **Copy received photos to the clipboard** (off by default). The clipboard gets
  the original image bytes, a decoded image and the saved file's URL, so pasting
  works in chat apps, image editors and Dolphin.
- **Open received links in the browser** (off by default, http/https only).
- Choose the folder for received files in Settings.
- The application icon follows the Plasma accent colour (System Settings →
  Colors). The tray icon is redrawn in Breeze style at 16 and 22 px and follows
  the panel's text colour, like other tray icons.

## Fixes

- Cancelling a send from the computer now actually tells the phone. The Cancel
  frame was queued and then thrown away when the socket was aborted.
- The mDNS announcement no longer answers for the computer's own
  `<hostname>.local`. That record conflicted with avahi-daemon on machines with
  several network interfaces and could make avahi rename the host.
- Received files go to the XDG Downloads folder (for example `~/Загрузки`)
  instead of a hard-coded `~/Downloads`.
- Starting the app while the background service is being activated over D-Bus
  no longer races with the service and fails with "no such object".
- `kquickshare file.txt` with a relative path now works from any directory.
- Fixed callbacks running on half-destroyed objects when a transfer or the send
  dialog is closed during shutdown.
- The text preview sent to the phone no longer splits an emoji in half.

## Code quality

- Source strings are English, as Qt and KDE expect; Russian is a regular
  translation catalog (`translations/kquickshare_ru.ts`).
- Stream framing, UKEY2 key derivation, the PIN code and BYTES reassembly have a
  single shared implementation instead of two diverging copies.
- All C++ follows the KDE Frameworks clang-format style, checked in CI.
  Builds use `-Wall -Wextra` and compile without warnings.
- New core tests for framing, payload reassembly, key agreement and the Cancel frame.

## Choose the right download

- `kquickshare-0.5.0.tar.gz`: source archive; extract and run `./install.sh` as your
  desktop user. Dependencies may require sudo. Requires Qt 6.8+, KF6 and OpenSSL 3.
- `kquickshare_0.5.0_amd64.deb`: **Debian 13 x86_64**, install with
  `sudo apt install ./kquickshare_0.5.0_amd64.deb`.
- `kquickshare-0.5.0-1.x86_64.rpm`: **Fedora 43 x86_64**, install with
  `sudo dnf install ./kquickshare-0.5.0-1.x86_64.rpm`.
- `PKGBUILD`: **Arch Linux**, review and run `makepkg -si` in its directory.
- `SHA256SUMS`: checksums for the attached files.

Do not install the Debian package on an arbitrary Ubuntu release, or the Fedora
RPM on openSUSE. Use the source installer if no matching package is available.

Both devices must be on the same LAN. Discovery needs UDP 5353, and incoming
transfers use TCP 53318 by default. Trust matching is based on device name, type
and IP, not a permanent verified key. This remains an AI-assisted community project.
