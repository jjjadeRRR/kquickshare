# KQuickShare 0.2.0

First public release of a native Quick Share application for KDE Plasma.

- Receive Android files through a tray application and actionable KDE notifications.
- Send files through Dolphin and send text using QR discovery.
- Save incoming files in Downloads, with collision-safe names and partial-file cleanup.
- Allow automatic reception from explicitly trusted devices on a trusted LAN.
- Optional send action in Plasma 6.8 clipboard history.
- Native C++ / Qt 6 / KDE Frameworks interface, with a user systemd service.

Tested on Arch Linux, Plasma 6.8 and Pixel 7 Pro in both directions. The interface
is currently in Russian. Transport uses the local network; BLE, Wi-Fi Direct and
Google-account contact discovery are not implemented. The trust allowlist matches
name, device type and IP address, rather than a persistent cryptographic identity.
The clipboard overlay is optional and specific to Plasma 6.8.

The source archive is built with `packaging/make-source.sh`. Its SHA-256 checksum
is supplied with the release. Arch users can build using the repository's
`packaging/PKGBUILD`; clipboard integration must be enabled separately.
