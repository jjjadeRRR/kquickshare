# KQuickShare 0.3.0

First public downloadable release of native Quick Share for KDE Plasma.

- Receive Android files through a tray application and KDE notifications.
- Send files from Dolphin and text through QR discovery.
- Optional automatic reception from trusted devices on a trusted LAN.
- Optional send button in Plasma 6.8 clipboard history.
- Automatic Russian/English interface based on the system UI language, with English fallback.
- Build, install and start from source with one command: `./install.sh`.

This is a vibe-coded project, developed with AI coding agents and tested by its
owner on Arch Linux, KDE Plasma 6.8 and a Pixel 7 Pro. Transport uses the LAN;
BLE, Wi-Fi Direct and Google-account contact discovery are not implemented.
The trust list matches name, type and IP address, not a persistent cryptographic identity.

## Downloads

- `kquickshare-0.3.0-1-x86_64.pkg.tar.zst`: Arch Linux x86_64 package.
  Install with `sudo pacman -U ./kquickshare-0.3.0-1-x86_64.pkg.tar.zst`.
- `kquickshare-0.3.0.tar.gz`: source archive; extract it and run `./install.sh`.
- `PKGBUILD`: build the Arch package with `makepkg -si`.
- `SHA256SUMS`: checksums of the provided files.

The package is not published on AUR. Clipboard integration is optional and must
be enabled separately, as described in the README. GPL-3.0-or-later, with original
KDE clipboard attribution and GPL-2.0-or-later notices preserved.
