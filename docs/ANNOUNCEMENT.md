# Announcement draft

## English

I made KQuickShare, a small native Quick Share application for KDE Plasma 6.
It sends and receives files using Android's built-in Quick Share, with a tray icon,
KDE notifications, a Dolphin action and optional automatic reception from trusted
devices. Received text can go straight to the clipboard; photos are saved as files.

The source installer supports Arch, Debian/Ubuntu, Fedora and openSUSE package
families. The repository includes compatibility tests, native packaging and a
list of what has actually been tested. Real-device testing so far is mainly on
Arch with a Pixel 7 Pro; reports from other systems are welcome.

This is an AI-assisted/vibe-coded project, inspired by NearDrop, and an independent
community project. It uses the local network; Wi-Fi Direct, BLE activation and
Google-account contact discovery are not implemented. The optional clipboard-history
button is experimental and specific to Plasma 6.8; normal transfers do not need it.

Source, installation, screenshots and limitations:
https://github.com/jjjadeRRR/kquickshare

## Русский

Сделал KQuickShare — небольшую нативную программу Quick Share для KDE Plasma 6.
Она отправляет и принимает файлы через встроенный Quick Share на Android:
есть трей, уведомления KDE, отправка из Dolphin и автоприём от доверенных устройств.
Полученный текст можно автоматически добавлять в буфер обмена; фото сохраняются в файлы.

Установщик поддерживает семейства Arch, Debian/Ubuntu, Fedora и openSUSE.
В репозитории есть проверки совместимости, сборка пакетов и список реально
проверенных систем. С настоящим телефоном пока больше всего проверяли Arch
и Pixel 7 Pro; буду рад отзывам с других дистрибутивов.

Это вайбкод-проект, сделанный с помощью ИИ и вдохновлённый NearDrop.
Он работает по локальной сети; Wi-Fi Direct, BLE-активации и обнаружения через
аккаунт Google нет. Дополнительная кнопка в истории буфера экспериментальная
и рассчитана на Plasma 6.8; обычная передача файлов от неё не зависит.

Исходники, установка, скриншоты и ограничения:
https://github.com/jjjadeRRR/kquickshare
